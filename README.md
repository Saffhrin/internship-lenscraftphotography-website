📷 LensCraft Photography — Photography Studio Website
---

A modern, responsive photography studio website developed during my web development internship. LensCraft showcases semantic HTML5 and CSS3 practices, a custom responsive grid system, smooth-scroll navigation, and an elegant, image-driven layout inspired by professional photography portfolios.

🔗 Live Demo:
https://saffhrin.github.io/internship-lenscraftphotography-website/

---

🔗 💼 Internship Details
---

**Position:** Web Development Intern
**Organization:** Gurumantra4U
**Duration:** June-July 2026

---

🔗 Responsibilities
---

- Designed and developed the full website structure and layout.
- Structured content using semantic HTML5.
- Built a custom responsive grid system using Flexbox (without a CSS framework).
- Implemented a sticky/scroll-aware navigation bar with a mobile dropdown menu.
- Added JavaScript interactivity for navbar scroll behavior and mobile menu toggle.
- Implemented Header, Body, and Footer section architecture.

---

🔗 ✨ Features
---

🔗 🏠 Home Section
- Full-screen hero header with background image and overlay text
- Bold call-to-action button ("Explore Portfolio")

🔗 ℹ️ Intro Section
- Brand introduction with icon accent
- Teal-themed highlight section

🔗 📸 Portfolio Sections
- Portrait Photography showcase with circular image and description
- Wedding Photography showcase with alternating image/text layout
- Promo grid highlighting Portraits, Landscapes, and Weddings with hover zoom effect

🔗 📞 Contact Section
- Clickable phone (`tel:`) and email (`mailto:`) links
- Clean, centered footer with copyright

---

🔗 📱 Responsive Design
---

- Mobile-friendly layout with a custom hamburger menu toggle (JavaScript)
- Tablet and desktop breakpoints via custom media queries
- Grid/column system built entirely with Flexbox

---

🔗 🎨 Modern UI Features
---

- Scroll-triggered navbar style change (transparent → white with shadow)
- Smooth color transitions on links, buttons, and promo tiles
- Circular image styling for portrait/wedding photos
- Hover-zoom effect on promo tiles
- Custom dropdown menu under "Services"
